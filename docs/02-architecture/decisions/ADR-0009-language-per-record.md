# ADR-0009: زبان در هر رکورد

- **وضعیت:** پذیرفته‌شده (2026-10-30).
- **تصمیم:** جدول ترجمه نداریم. هر رکورد محتوایی `language_id` دارد و ادمین هنگام ایجاد زبان را انتخاب می‌کند. `languages` امکان افزودن زبان‌های بیشتر را می‌دهد (مسیرها از دیتابیس خوانده می‌شوند).
- `translation_key` اختیاری، فقط برای hreflang و سوییچ زبان. اگر معادل نبود، سوییچ به خانهٔ آن زبان می‌رود.
- slug فارسی و یکتا در دامنهٔ (زبان، صفحه). slug رکورد حذف‌شده رزرو می‌ماند.
- **ریسک:** ناسازگاری بین رکوردهای هم‌کلید؛ با اعتبارسنجی فرم و قید یکتایی (کلید، زبان) کنترل می‌شود.
