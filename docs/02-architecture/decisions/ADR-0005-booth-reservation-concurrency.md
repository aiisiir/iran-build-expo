# ADR-0005: رزرو غرفه، هم‌زمانی و انقضا

> **منسوخ (2026-10-30):** در نسخهٔ CMS ساخته نمی‌شود؛ به سیستم جداگانهٔ ثبت‌نام شرکت‌ها منتقل شد. ADR-0008 را ببینید.

- **وضعیت:** پیشنهادی (منتظر تأیید دیتابیس)
## تصمیم
رزرو داخل یک تراکنش: قفل ردیف غرفه (`SELECT … FOR UPDATE`) → منقضی‌کردن رزروهای `held` گذشتهٔ همان غرفه/شرکت → درج رزرو و پیش‌فاکتور. دو قید `UNIQUE` روی ستون‌های محاسبه‌شده، آخرین خط دفاع‌اند؛ خطای یکتا (1062) به پیام «غرفه گرفته شد / شرکت غرفه دارد» تبدیل می‌شود. زمان‌ها در PHP محاسبه می‌شوند (`now()`) تا قابل تست باشند.
## بدون cron
انقضا lazy است؛ صفحات عمومی `held` منقضی را آزاد حساب می‌کنند. اگر cron بعداً فراهم شد، فقط پاک‌سازی اضافه می‌شود.
## مسائل باز
پرداخت پس از انقضا (OPEN-012)؛ سقف تلاش رزرو/لغو پشت‌سرهم (rate limit) برای جلوگیری از احتکار؛ تأیید ادمین روی `held` منقضی: پیشنهاد = رد، شرکت دوباره رزرو کند.
