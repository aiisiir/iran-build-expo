# ADR-0011: هویت بصری و UI صفحهٔ اصلی

- **وضعیت:** پذیرفته‌شده (2026-11-01)، فقط صفحهٔ اصلی؛ بقیهٔ صفحه‌ها پس از تأیید مالک.
- **معماری:** بدون تغییر (Laravel + Blade، SSR). بدون وابستگی جدید، بدون کتابخانهٔ انیمیشن. تغییر schema ندارد (ستون `display` رشته است؛ مقدار `hero` اضافه شد).
- **توکن‌ها:** در بالای `public/css/site.css` (navy / cream / gold، فاصله، سایه، شعاع، فونت). نسبت‌های کنتراست محاسبه‌شده کنار توکن‌ها نوشته شده. طلایی `gold-500` فقط تزئینی است (۲٫۷ روی cream)؛ هرگز متن نیست.
- **هدر:** در بالا cream و بلند؛ با اسکرول به navy و کوتاه. یک متغیر `--p` (۰..۱) ارتفاع و رنگ را می‌راند: `animation-timeline: scroll()` در مرورگرهای پشتیبان، و در بقیه یک `IntersectionObserver` (بدون listener اسکرول). نگه‌دارندهٔ ارتفاع ثابت جلوی CLS را می‌گیرد.
- **هیرو:** دقیقاً ۴ اسلاید. منبع: ماژول «پست» با نمایش `hero` در صفحهٔ اصلی (حداکثر ۴)، وگرنه ۴ تصویرسازی اصلی و موقت (`public/images/hero/`). دکمهٔ CTA فقط وقتی رکورد مقصد معتبر دارد. اولین تصویر `eager` + `fetchpriority=high`. خودکار فقط وقتی `prefers-reduced-motion` نیست، و همیشه قابل توقف.
- **ویدیو:** فایل از `home_video_url` در تنظیمات (فقط مسیر محلی)، پیش‌فرض یک حلقهٔ انتزاعی ۲۴۰KB (`public/video/atmosphere.mp4`، موقت). `preload=none`، بی‌صدا، فقط هنگام دیده شدن، با دکمهٔ توقف؛ با reduced-motion یا data-saver فقط پوستر.
- **لوگو:** نماد ستارهٔ هشت‌پر (دو مربع) + طاق جناغی + سنگ‌کلید طلایی؛ نام برند تغییر نکرد (Iran Build Expo). فایل‌ها در `public/brand/`. در هدر/فوتر به‌صورت SVG درون‌خطی با `currentColor` برای رنگ‌گیری از زمینه.
- **باز است:** عکس‌های واقعی هیرو، ویدیوی واقعی، نام فارسی برند (برای لوگوی فارسی)، اندازه‌گیری LCP/CLS/INP روی هاست واقعی.
