# ADR-0008: دامنهٔ CMS و مدل داده

- **وضعیت:** پذیرفته‌شده (2026-10-30). جایگزین ADR-0005، ADR-0006 و ADR-0003.
- **زمینه:** محصول به «سایت عمومی نمایشگاه + CMS» تغییر کرد. غرفه، رزرو، پیش‌فاکتور، پرداخت، QR و اسکن در سیستم جداگانه ساخته می‌شود.
- **تصمیم:**
  1. محتوا با `pages` + `page_modules` ساخته می‌شود؛ منو/لوگو/حامیان/برگزارکنندگان/لینک‌ها با یک سازوکار (`link_groups` + `links`).
  2. خبر/اطلاعیه/پوستر یک جدول (`posts`) با دسته است.
  3. «تاریخچهٔ نسخه» ساخته نمی‌شود؛ فقط Soft Delete (بازیابی در نسخهٔ بعد).
  4. نقش‌ها فقط `admin` و `editor`؛ `position` نمایشی است.
  5. پنل ادمین Blade سبک خودمان (نه Filament) چون با CSP سخت‌گیر سازگارتر است.
- **پیامد:** مستندات و ERD قدیمی (غرفه/QR/پرداخت) منسوخ‌اند و در «نسخهٔ آینده» می‌مانند.
