# ADR-0007: پول، زمان و زبان

- **وضعیت:** پذیرفته‌شده (جز موارد مشخص‌شده)
- **پول:** ریال، `BIGINT UNSIGNED`، قیمت نهایی (مالیات/کسورات داخل عدد). float ممنوع.
- **زمان:** منطقهٔ `Asia/Tehran` در Laravel و ذخیرهٔ همان زمان (ایران DST ندارد)؛ `service_date` تاریخ محلی است. اگر قانون DST تغییر کند، این ADR بازبینی شود.
- **جلالی:** پیاده‌سازی داخلی `App\Support\Jalali` (الگوریتم استاندارد jalaali) با تست مقادیر مرجع؛ بدون وابستگی خارجی. دیتابیس فقط میلادی.
- **ارقام:** تبدیل به ارقام فارسی هنگام نمایش در سرور (`App\Support\Digits`) و نرمال‌سازی ورودی؛ به ویژگی‌های فونت تکیه نمی‌شود.
- **فونت:** Vazirmatn (فارسی)، Poppins (انگلیسی)، self-host، `woff2`، لایسنس OFL.
