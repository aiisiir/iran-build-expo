# ADR-0002: زبان و URLهای عمومی

- **وضعیت:** پذیرفته‌شده برای پایلوت
- **تاریخ:** 2026-10-27

## تصمیم
مسیرهای عمومی به‌صورت `/fa/...` و `/en/...` هستند. URL صفحه باید معادل زبانی همان محتوا را معرفی کند. ریشهٔ `/` در نسخهٔ اول به `/fa` منتقل می‌شود. مسیرهای فارسی با `dir="rtl"` و مسیرهای انگلیسی با `dir="ltr"` رندر می‌شوند.

## الزامات
- canonical هر زبان به URL خودش اشاره می‌کند.
- hreflang برای معادل‌های واقعی متقابل است (`fa-IR`، `en`) و `x-default` مطابق سیاست صفحه تنظیم می‌شود.
- انتشار هر زبان مستقل است؛ لینک زبان ناموجود نباید به صفحهٔ خالی یا محتوای زبان دیگر به‌عنوان معادل کامل اشاره کند.
- slug ترجمه‌شده و سیاست redirect در مدل CMS باید مشخص شود.
- لینک‌های داخلی ترجیحاً route نام‌گذاری‌شده و محلی‌شده باشند.

## پیامد
نقشهٔ سایت و metadata باید از نگاشت شناخته‌شدهٔ محتوای فارسی/انگلیسی تغذیه شوند؛ جایگزینی سادهٔ رشتهٔ `/fa` با `/en` برای همهٔ مسیرهای پیچیده کافی نیست.
