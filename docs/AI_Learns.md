# AI_Learns — حافظهٔ پروژه برای نشست‌های بعدی Claude

> هر تصمیم/درس مهم اینجا و در چت ثبت می‌شود. تاریخ‌ها شمسی نیست، میلادی است.

## سبک کار مالک
- فارسی، کوتاه و صریح. بدون اضافه‌گویی. مالک با Git تازه‌کار است؛ دستورها را قدم‌به‌قدم بده.
- عبارت تأیید هر فاز: «**فاز X تمام، قدم بعدی را بردار**». اگر عبارتی شبیه آن بود ولی دقیق نبود، بپرس.
- ۲۰۲۶-۱۰-۲۸: مالک صراحتاً گفت فازهای ۱، ۲ و ۳ را پشت‌سرهم پیش ببر؛ فقط خروجی طراحی دیتابیس (فاز ۲) را برای تأیید نشان بده. **migration قبل از تأیید دیتابیس ساخته نمی‌شود.**
- هرگز `mainstructure` را تغییر نده. commit/push فقط روی branch `claude`؛ مالک merge می‌کند.
- افزودن کتابخانه/افزونه فقط با توضیح فایده و تأیید.

## تصمیم‌های قطعی
- Laravel 13 + Blade، PHP 8.4 (قفل Composer روی 8.4)، MariaDB 10.4.34 (EOL؛ ریسک ثبت شد).
- استقرار: ساب‌دامین `iranbuildexpo.mahdiarmansouri.ir`؛ `app/` کنار `public_html/`. بدون SSH؛ SQL دستی با phpMyAdmin؛ بدون queue/cron.
- ورود: نام‌کاربری/رمز hash‌شده؛ OTP بعداً؛ کد ثابت وجود ندارد.
- پول: ریال، عدد صحیح، قیمت نهایی. رزرو غرفه ۳ ساعت، ۱ غرفه برای هر شرکت.
- فونت‌ها: Vazirmatn، Poppins (self-host). تقویم جلالی: پیاده‌سازی داخلی.
- ریسک‌های هاست اشتراکی: به مالک نشان بده و ثبت کن، ولی پایلوت را متوقف نکن.
- پروژهٔ `lab` (دامنهٔ mahlinsaffron.ir) ربطی به این پروژه ندارد.

## محدودیت‌های محیط Claude (شناخته‌شده)
- `composer install` در محیط Claude مسدود است (packagist ۴۰۳)؛ تست‌ها و vendor را مالک روی لوکال اجرا می‌کند. هر تست اجرانشده باید «اجرا نشد» برچسب بخورد.
- push به GitHub نیازمند نصب اپ Claude روی ریپو است؛ در غیر این صورت زیپ/bundle تحویل بده.

## درس‌ها / نکات فنی
- Laravel 13 فقط به PHP 8.3–8.5 نیاز دارد؛ اسکلت رسمی را از `github.com/laravel/laravel` (branch 13.x) بگیر، از حافظه کانفیگ ننویس.
- MariaDB قید یکتای جزئی ندارد؛ از ستون محاسبه‌شده + UNIQUE استفاده کن (NULL چندبار مجاز است).
- ارقام فارسی را در سرور تبدیل کن؛ به ویژگی‌های فونت تکیه نکن.
- تصویر OG فعلی placeholder است؛ قبل از production جایگزین شود.

## به‌روزرسانی 2026-10-30 (تغییر دامنه به CMS)
- محصول: سایت عمومی + CMS. **بدون** غرفه/رزرو/پرداخت/QR (سیستم جدا). نقش‌ها admin/editor.
- زبان در هر رکورد (`language_id`)، `translation_key` اختیاری. slug فارسی؛ رکورد حذف‌شده slug را رزرو نگه می‌دارد. همه‌چیز Soft Delete؛ نسخه‌بندی محتوا نه.
- رمز: bcrypt (Argon2id به هاست اتکا نکن). حداقل ۶ کاراکتر، قفل ۵ تلاش (تصمیم مالک؛ ریسک را بگو).
- آپلود: تصویر ≤ ۲MB. SVG در رسانه مجاز (فقط `<img>`، XML را parse نکن)، در متن غنی ممنوع. EXIF حذف می‌شود (امنیتی است، نه ریسک).
- `X-Frame-Options` را مالک اشتباه برداشت کرد: این هدر کنترل می‌کند چه کسی صفحهٔ ما را frame کند؛ تور سه‌بعدی با `frame-src` در CSP ما و هدرهای سایت تور کنترل می‌شود. جای‌نگه‌دار `DUMMY-3DTour`.
- ویرایشگر: Jodit (MIT)؛ npm/CDN از سرور Claude بسته است، فقط `git clone` از GitHub کار می‌کند. CKEditor4 فقط آخرین راه (EOL).
- محیط تست: packagist بسته است؛ با composer و مخزن‌های vcs از GitHub وابستگی‌ها ساخته می‌شود (کند). PHP محلی ۸.۳ است.
- مالک می‌خواهد کم‌توکن و سریع جلو برویم؛ سؤال اضافه نپرس، با پیش‌فرض ادامه بده و در گزارش بگو.
