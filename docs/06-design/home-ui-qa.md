# QA صفحهٔ اصلی (UI جدید)، 2026-11-02

## اجرا شد
- PHPUnit روی sqlite (PHP 8.3.6 محلی): 78 تست، 40414 assertion، همه سبز. (هاست: PHP 8.4 و MariaDB؛ این‌ها اجرا نشده‌اند.)
- Chromium (Playwright) روی سرور محلی PHP با CSP اجباری: fa/en × دسکتاپ 1440 / موبایل 390 — بدون خطای console، بدون پاسخ ≥400، بدون کوکی، بدون سرریز افقی.
- Chromium روی HTML ایستا: تبلت 820؛ اسلایدر (بعدی، قبلی، توقف، فلش‌ها، پخش خودکار ۷ثانیه)، reduced-motion (بدون پخش خودکار، ویدیو فقط پوستر)، منوی موبایل با Esc، کوچک‌شدن هدر (96 → 64px).
- کنتراست محاسبه‌شده از رنگ‌های واقعی DOM برای همهٔ متن‌های دیده‌شده (fa/en، دو اندازه، بالا و پایین اسکرول): همه ≥ AA و ≥ AAA برای متن عادی، با این قید که متن روی هیرو/ویدیو با روکش نیمه‌شفاف روی سفید (بدترین حالت) سنجیده شده، نه روی هر عکس دلخواه.
- اندازه‌گیری آزمایشگاهی (بدون throttle، لوکال): LCP = تصویر اول هیرو، CLS ≈ 0.

## اجرا نشد / محدودیت
- axe یا Lighthouse (npm و CDN بسته است): ممیزی خودکار WCAG کامل نشد؛ ادعای «AAA کامل» نمی‌کنیم.
- Firefox و Safari؛ فقط Chromium. fallback هدر (بدون scroll-timeline) فقط در منطق بررسی شد.
- screen reader واقعی؛ LCP/INP روی هاست و شبکهٔ واقعی.
- وسط انتقال هدر (حدود ۱۴px اسکرول) کنتراست لحظه‌ای کمتر از AA است.
- عکس و ویدیوی هیرو موقت‌اند؛ باید با محتوای واقعی از CMS جایگزین شوند.

## باگ‌هایی که اجرای واقعی پیدا کرد (اصلاح شد)
- `Audited`: ثبت رویداد مدل با `static::{$event}` در boot خطا می‌داد → `registerModelEvent`.
- کش مدل Eloquent در لاراول 13 ممنوع است (`serializable_classes=false`) → زبان‌ها به‌صورت آرایه کش می‌شوند.
- `pagination::default` وجود نداشت → view اختصاصی.
- سوئیچر زبان زبان فعلی را هم نشان می‌داد (`except` روی کلید مدل).
- در partialهای صفحهٔ اصلی `$language`/`$site` هنوز در دسترس نبود.
