# راهنمای مختصر برند

**نماد:** ستارهٔ هشت‌پر (دو مربع روی هم) با طاق جناغی در مرکز و یک لوزی طلایی (سنگ‌کلید). کوچک‌ترین اندازهٔ خوانا: ۱۶px (favicon).

| رنگ | مقدار | کاربرد |
|---|---|---|
| Navy 900 | `#0F2240` | متن عنوان، زمینهٔ تیره، نماد |
| Cream 100 | `#F5EFE2` | زمینهٔ هدر و بخش‌ها |
| Cream 50 | `#FBF8F1` | زمینهٔ صفحه |
| Gold 500 | `#B88A2C` | تزئین (نه متن) |
| Gold 300 | `#E3C170` | تأکید روی navy |

فضای خالی دور لوگو ≥ ارتفاع طاق (حدود ۳۰٪ ارتفاع نماد). روی عکس شلوغ از نسخهٔ تک‌رنگ یا زمینهٔ تیره استفاده کنید. تغییر رنگ، کشیدن یا چرخاندن لوگو ممنوع است.

| فایل (`public/brand/`) | کاربرد |
|---|---|
| `symbol.svg`, `symbol-dark.svg`, `symbol-mono.svg` | نماد روی روشن / تیره / تک‌رنگ (چاپ، مهر) |
| `logo-horizontal*.svg`, `logo-vertical*.svg` | لوگوتایپ (متن به منحنی تبدیل شده) |
| `logo-print.pdf` | برداری، آمادهٔ چاپ (سربرگ، پاکت) |
| `social-square.png`, `social-profile.png` | شبکه‌های اجتماعی |
| `favicon*.png`, `icon-192/512.png`, `public/favicon.ico`, `public/apple-touch-icon.png` | آیکون‌ها |
| `public/images/og-default.png` | تصویر OG (1200×630) |

نام فارسی برند هنوز تعیین نشده؛ لوگوتایپ فقط لاتین است. متن نام سایت از تنظیمات هر زبان می‌آید.
