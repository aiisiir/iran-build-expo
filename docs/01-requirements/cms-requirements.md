# نیازمندی‌های نسخهٔ CMS (جایگزین بخش غرفه/پرداخت در SRS)

> SRS بخش ۶ و «معیارهای پذیرش افزوده‌ها» دربارهٔ رزرو غرفه/پیش‌فاکتور/QR منسوخ‌اند (سیستم جدا). این فایل مرجع فعلی است.

## نیازمندی‌ها
| ID | نیازمندی | معیار پذیرش |
|---|---|---|
| CMS-01 | چندزبانه: هر رکورد زبان خودش را دارد؛ زبان جدید با افزودن ردیف `languages` | `/fa` و `/en` از دیتابیس؛ زبان نامعتبر 404؛ رکورد یک زبان در زبان دیگر نمایش داده نمی‌شود |
| CMS-02 | صفحه + بلوک‌ها (اخبار، لینک، متن/تصویر، گالری، FAQ، شرکت‌ها، تور) با عنوان، نمایش عنوان، روشن/خاموش، ترتیب | بلوک خاموش رندر نمی‌شود؛ ترتیب با `sort_order` |
| CMS-03 | خبر/اطلاعیه/پوستر با دسته، انتشار زمان‌بندی‌شده و انقضا بدون cron | پرس‌وجو `published_at ≤ now` و `expires_at > now` (تست) |
| CMS-04 | آدرس‌ها `/زبان/صفحه/خبر` و `/زبان/صفحه/شرکت/محصول`؛ slug فارسی یکتا؛ slug حذف‌شده رزرو | تست‌های DataModelTest |
| CMS-05 | منو چندسطحی، لوگو، حامیان، برگزارکنندگان، لینک‌های سریع و فوتر با یک سازوکار لینک | منو از `link_groups`؛ زیرمنو |
| CMS-06 | سئو: canonical، hreflang از `translation_key`، sitemap فقط رکوردهای عمومی، JSON-LD فقط دادهٔ قابل‌مشاهده، noindex در غیر production | تست‌های PublicSiteTest |
| CMS-07 | امنیت محتوا: HTMLPurifier هنگام ذخیره و نمایش؛ iframe فقط در یک صفحهٔ تور؛ CSP عمومی سخت‌گیر | HtmlSanitizerTest، تست frame-src |
| CMS-08 | آپلود: تصویر ۲MB، PDF ۲۰MB، بازنویسی تصویر (حذف EXIF)، SVG فقط تصویر، بدون اجرای PHP | UploadsTest |
| CMS-09 | ورود ایمیل/رمز، نقش admin/editor، قفل بعد از ۵ تلاش ناموفق، رمز ≥ ۶ کاراکتر (bcrypt) | AdminTest |
| CMS-10 | Soft Delete برای همهٔ رکوردها؛ لاگ فعالیت بدون مقدار فیلدها | DataModelTest، AdminTest |
| CMS-11 | فرم عمومی کارت سینه (تلفن/ایمیل/جنسیت اجباری)، تأیید و ویرایش ادمین، چاپ ۶×۱۵ سانتی‌متر، داده رمزشده، عکس خصوصی، بدون دانلود | BadgeTest |

## خارج از دامنه (نسخهٔ آینده)
غرفه و سالن، رزرو، پیش‌فاکتور و پرداخت، QR و اسکن، ورود شرکت‌ها، نشست‌ها، بازیابی رکورد حذف‌شده از پنل، تاریخچهٔ نسخهٔ محتوا، تاریخ شمسی در ورودی پنل، صفحه‌بندی آرشیو اخبار.
