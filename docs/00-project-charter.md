# منشور پروژه — Iran Build Expo

## مسئله
به یک سامانهٔ یکپارچه برای معرفی و مدیریت دوره‌های نمایشگاه، شرکت‌ها، محصولات، جانمایی غرفه‌ها، ثبت‌نام بازدیدکنندگان، ارتباطات B2B و عملیات مدیریتی نیاز داریم. سایت عمومی باید برای موتورهای جست‌وجو قابل خزش و از نظر فنی قابل رقابت باشد.

## اهداف
- معرفی چند دورهٔ نمایشگاه و نگهداری آرشیو دوره‌های گذشته.
- انتشار صفحات عمومی فارسی و انگلیسی با URL مستقل.
- مدیریت شرکت‌ها، محصولات، غرفه‌ها، بازدیدکنندگان، سرنخ‌های تجاری و محتوای سایت.
- ارائهٔ اطلاعات و گزارش‌های قابل اتکا برای اپراتورهای نمایشگاه.
- حفظ امکان توسعهٔ پرداخت آنلاین در آینده بدون پیاده‌سازی آن در نسخهٔ اول.

## خارج از محدودهٔ v1
- درگاه و تسویهٔ آنلاین.
- اپلیکیشن موبایل مستقل.
- SPA یا فرانت‌اند React جداگانه.
- ورود با شبکه‌های اجتماعی، چت زنده یا قابلیت‌هایی که در SRS تصویب نشده‌اند.

## معیار موفقیت
موفقیت با تکمیل سناریوهای پذیرش، صحت جداسازی داده، پایداری تخصیص غرفه، قابل‌خزش‌بودن صفحات عمومی، آزمون‌های بازیابی و تحویل مستندات عملیاتی سنجیده می‌شود؛ صرفاً با تعداد قابلیت‌ها یا نمرهٔ Lighthouse تعریف نمی‌شود.

## تصمیم‌های فعلی
- پایلوت: Laravel + Blade، رندر سمت سرور.
- PHP هدف: 8.3+ برای Laravel 13؛ هاست باید پیش از Deploy تأیید شود.
- زبان‌ها: `/fa/...` و `/en/...`.
- پایگاه دادهٔ اولیه: رابطه‌ای، MySQL/MariaDB گزینهٔ هدف.
- پرداخت: خارج از محدودهٔ v1.
